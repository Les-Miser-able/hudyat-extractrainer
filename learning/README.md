# Gesture training lessons

Start with [Lesson 01: Train two gestures](lessons/0001-train-two-gestures.html).
For video inputs, continue with [Lesson 02: Prepare gesture videos](lessons/0002-prepare-gesture-videos.html)
and its [video preprocessing reference](reference/video-preprocessing.html).

For the complete current preparation flow, open
[Lesson 03: Follow one recording](lessons/0003-follow-dataset-pipeline.html)
and the [dataset pipeline reference](reference/dataset-pipeline.html). These cover
named dataset versions, source grouping, image/video differences, saved artifacts,
and the handoff to training and prediction.

Keep the [quick reference](reference/gesture-training.html) nearby while practicing.

- [Learning mission](MISSION.md): the exercise and what success looks like.
- [Teaching notes](NOTES.md): progress, open questions, and the next session.
- [Resources](RESOURCES.md): the project contract and primary reading.
- [Project guide](../README.md): commands, input requirements, and training details.

The `assets/` folder holds the styles and quiz logic shared by the HTML lessons
and reference pages. Open those pages locally; their links and assets stay relative
to this folder. Run all Python commands from the repository root, one level above
this directory, using the environment with the ML requirements installed.
