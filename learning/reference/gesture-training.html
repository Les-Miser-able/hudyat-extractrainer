FSL training lab / Field notes

From examples to a model.

A quick reference for the existing Conv1D–BiLSTM trainer.

The terms

Category
One independent model, for example practice or alphabet.
Class
One label that the category model can predict, such as open_palm or A.
Source group
Related recordings kept in one split. Synthetic variants remain with their original source. Signer/session CSVs can group several originals.
Preparation
Extract landmarks where needed, split source groups, and save fixed-shape sequences.
Training
Fit the classifier’s parameters using the training split; use validation loss to select its saved checkpoint.
Epoch
One pass through the training data.
Prediction
Apply a saved model to a sample and score its known classes.

The working contract

Source layoutdata/<category>/<class>/<file>
MinimumTwo classes, each with at least three accepted independent source groups
Static poseAn image; repeated across 32 frames, with jitter variants during preparation
Moving gestureA full video recording; interpolated to 32 frames
Classifier input32 timesteps × 128 landmark/presence features
Default split targets70% training / 15% validation / 15% test; rounding and group sizes can change this
Default augmentation8 static variants, coordinate jitter standard deviation 0.0075
Saved modelruns/<category>/<run>/best.keras, with classes.json and preprocessing.json

Source of these exact settings: repository guide and trainer implementation. The three-group minimum checks feasibility, not real-world accuracy.

The shortest safe workflow

  1. Collect correctly labeled, independently captured examples.
  2. Set a fresh dataset name beneath your selected dataset root. Prepare and read any extraction rejections.
  3. Train into a fresh run name. Keep the dataset root consistent.
  4. Review validation behavior and held-out test results.
  5. Predict a new recording saved outside the prepared source category.

For signer/session separation, use --groups-dir groups with one category CSV, for example groups/practice.csv, containing path,group rows. The dashboard preparation form accepts the individual category CSV through Group CSV. See split and grouping instructions.

When something blocks you

SymptomCheck first
No gesture foldersThe selected source root must contain a category with class subfolders; .gitkeep is not data.
Not enough groupsCollect new independent recordings. More copies or jitter do not add groups.
Extraction rejected filesRead the extraction report; check visible hands and decodable media.
Output already existsChoose a new dataset name or run name; preserve existing artifacts.
Import/dependency errorLaunch the dashboard with the Python environment where requirements.txt is installed.
Good training score, poor new predictionsCheck held-out results, recording conditions, labels and group separation before changing hyperparameters.
