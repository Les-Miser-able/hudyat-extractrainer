Category chooses the independent model task. The next folder gives the gesture label. S1 can be selected under source folders, but its name does not automatically establish a signer group.

The dashboard's Dataset name selects the output version. A fresh name preserves older versions; the name itself does not enable augmentation. Source filtering chooses what enters this version without changing the original files.

02 / Convert the recording

One frame becomes 128 values.

Left hand:  21 landmarks × (x, y, z) = 63
Right hand: 21 landmarks × (x, y, z) = 63
Presence:   left flag + right flag  =  2
                                      ───
                                      128

An image gives one landmark frame. A video with T decoded frames gives a sequence shaped (T,128). Existing compatible .npy landmarks skip MediaPipe detection. Missing hands have zero coordinates and a zero presence flag.

The project uses MediaPipe's image-relative coordinates. It adds no centering or hand-size normalization. Existing arrays must already follow the same coordinate and presence conventions.

03 / Decide which split owns the source

Split the source group before making variants.

Training updates the classifier. Validation supplies feedback during training. Test is used to evaluate the selected model. A source group must belong to just one split; all derived samples inherit that assignment.

The default targets are 70% training, 15% validation, and 15% test. Counts can differ because whole groups must stay together. Three independent groups per gesture is a processing minimum; with exactly three class-local groups, one goes to each split.

Overlapping clips from one recording should share an explicit group ID. If the same signer or session must stay together, provide that relationship in a Group CSV. Folder selection alone does not do this.

split_sources · Primary reading: why grouped samples need separate splits. This project implements its own splitter; it does not call scikit-learn.

04 / Produce the common input

Every prepared sample is 32 × 128.

For a moving sequence, the code interpolates the full landmark timeline to 32 timesteps. It does not take only the first 32 frames. Coordinates use linear interpolation; presence flags use the nearest frame and absent-hand coordinates are zeroed again.

For a static source, the single pose is repeated to 32 timesteps and jitter is added to detected-hand coordinates. The default is eight such sequences. Current behavior: this static generation applies in whichever split owns the source, including validation and test. Optional video timing extras apply only to training sequences.

05 / Validate, then hand off to training

Use the dataset's exact version.

Preparation checks array shapes, valid numbers, binary presence flags, class coverage, and source-group separation. It writes the manifest, preprocessing settings, and augmentation summary. The media path also keeps original-length extracted landmarks and an extraction report.

python categories.py prepare --category practice_video --dataset-name baseline_v1
python trainer.py inspect --dataset datasets_augmented/practice_video/baseline_v1
python categories.py train --category practice_video --dataset-name baseline_v1 --run model_v1

Run these from the repository root with the Python environment containing the project requirements. Preparation and training are separate jobs; the commands above are examples and are not run by this lesson.
