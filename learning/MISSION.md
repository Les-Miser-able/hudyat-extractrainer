# Mission: Train a small gesture model

## Why
Learn to train a few gestures as a practical exercise in this FSL trainer
workspace. Turn original hand recordings into a local classifier and try it
on a new example, while understanding what each stage does.

## Success looks like
- Organize two gesture classes into correctly labeled source folders.
- Explain why augmented copies are not independent training sources.
- Prepare a dataset, train a fresh category model, and locate its checkpoint.
- Test a recording that was not included in preparation.

## Constraints
- Use the existing Windows project and its local dashboard or Python commands.
- Use a Python environment with the project's ML dependencies installed.
- Begin with a small learning exercise; accuracy is not yet a production goal.

## Out of scope
- No additional exclusions stated.
