PREPARATION

Source selection

Folder choices apply beneath each gesture, including nested clips. Choose S1, S2, S3 and leave PUB unchecked to exclude it. Gestures with no matching files are omitted. These choices do not group signers: use a Group CSV for signer/session isolation.

Landmark preprocessing

Alphabet images/videos use hand-relative coordinates with movement preserved. Other categories keep original coordinates. Automatic jitter: 0.03 palm lengths or 0.0075 image units. Hand-relative training adds rotation and mirror variants for static poses; validation/test use one clean sequence per source. Prepare a new dataset and train a new run to use it.

Video / sequence augmentation

Zero extra samples keeps augmentation off; try 3 to start. Extras apply only to training videos and multi-frame landmark inputs. Originals are kept; motionless clips may yield fewer extras. Timing strength 0.05 allows a shift of up to 5% of the gesture timeline (greater than 0, maximum 0.10).

Extraction settings

Existing datasets are protected. Choose a new dataset name to prepare another version. The trainer checks independent groups after extraction.

Benchmark metrics

The same category and Preferred filters apply to this table and its CSV.

Accuracy, macro precision, macro recall, and macro F1 must each reach 85%; every sign must reach 70% recall. Required counts: Alphabet 26, Numbers 10, Colors 6, Greetings 10. All signs need held-out test samples.

Response time is full HUDYAT camera-to-confirmed-result time on the browser/device used for testing. Select HUDYAT camera test, open it from Activity, perform each sign, and save the automatically timed trials. Met requires all signs tested, no timeouts, and median response strictly below 1,000 ms. Local inference is a separate diagnostic. The current HUDYAT code requires 1.2 seconds of alphabet stability or a two-second clip for other categories.

Recognition timing

Changes apply on the next camera frame. Lower delays respond sooner; higher delays tolerate longer pauses or tracking gaps. Frame interval controls update frequency in every mode; finish delays apply to movement modes.

Perform the whole gesture, then hold the ending still or lower your hands. The selected delay finishes capture and keeps the result visible; brief tracking gaps remain buffered. Moving gesture automatically captures the next movement. Perform once waits for Next gesture. Capture allows up to six seconds; held pose uses only the current pose.
